El propósito de este proyecto es entender la situación poblacional 
de la alcaldía Iztacalco ubicada en la Ciudad de México 
con datos recolectados de los censos de población elaborados
por parte del INEGI (https://www.inegi.org.mx/).

El código fue diseñado y realizado de tal manera que sea legible y 
reutilizable en futuros proyectos, tratando de mantener la máxima
compatibilidad y eficiencia de recursos posible.

Se adjunta un ensayo realizado a partir de las conclusiones
obtenidas así como una explicación más a fondo de los procesos
realizados a lo largo de este proyecto en formato pdf en la carpeta
raíz del proyecto.  

Este proyecto fue realizado para el curso de Demografía de la
profesora Irene Nava Ruiz impartida en la Facultad de Ciencias,
UNAM. No se hizo uso de ningún modelo de LLM durante su realización.
